## Deskripsi
Repository ini berisi latihan Praktikum 2 HTML Lanjutan, meliputi tabel HTML, form dan berbagai jenis input, semantic HTML, multimedia, serta validasi form dasar.

## Struktur Folder
```text
Lab2Web/
├── index.html
├── biodata.html
├── media/
│   ├── audio.mp3
│   └── video.mp4
├── screenshots/
└── README.md
```

## Langkah Praktikum
1. Membuat tabel data mahasiswa menggunakan `table`, `tr`, `th`, dan `td`.
2. Mengembangkan tabel dengan `caption`, `thead`, `tbody`, `tfoot`, dan `colspan`.
3. Membuat form registrasi dengan input teks, email, password, dan tanggal.
4. Menggunakan radio button untuk pilihan tunggal dan checkbox untuk pilihan lebih dari satu.
5. Menggunakan `select` dan `textarea`.
6. Menerapkan validasi HTML menggunakan `required`, `minlength`, `min`, `max`, dan `type`.
7. Menyusun halaman dengan semantic HTML seperti `header`, `nav`, `main`, `section`, `article`, dan `footer`.
8. Menambahkan elemen audio dan video.
9. Membuat proyek mini biodata mahasiswa pada `biodata.html`.

## Cara Menjalankan
1. Unduh atau clone repository ini.
2. Buka folder `Lab2Web` menggunakan Visual Studio Code.
3. Buka file `index.html` di browser.
4. Klik tautan **Biodata Mahasiswa** untuk membuka `biodata.html`.
5. Uji form dengan mencoba mengirim form tanpa mengisi kolom wajib.

## Multimedia
Simpan file audio dengan nama `audio.mp3` dan video dengan nama `video.mp4` di dalam folder `media/`. Gunakan file yang memang boleh digunakan untuk tugas.

## Screenshot
Simpan screenshot tampilan hasil praktik ke folder `screenshots/`, lalu tambahkan gambar ke README dengan format berikut:

```markdown
![Tabel data mahasiswa](screenshots/tabel-mahasiswa.png)
![Form registrasi](screenshots/form-registrasi.png)
![Biodata mahasiswa](screenshots/biodata-mahasiswa.png)
![Validasi form](screenshots/validasi-form.png)
```

Pastikan nama file screenshot sama dengan nama yang ditulis di README. Ambil screenshot dari browser setelah halaman benar-benar dijalankan.

## Catatan
Form HTML pada praktikum ini hanya menunjukkan input dan validasi dasar di browser. Data belum disimpan ke database karena backend belum menjadi bagian dari materi ini.
